# Interaction module for Unreal Engine

## Overview
This Unreal Engine module is an example of how one can create interaction system when players can interact with various actors on level. 

It is multiplayer ready (all default net modes supported : single player, dedicated server or listen server). 

The idea behind it is to create an interaction system in data-driven like manner. With it the best case scenario is when developers would provide building blocks for designers to use.

It is both fully C++ and Blueprints ready. However I would recommend make all logic parts in C++ and setup in BPs/Instances.
